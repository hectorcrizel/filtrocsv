# CSV Filter & Formatter

![Python](https://img.shields.io/badge/Python-3.x-blue.svg)
![Pandas](https://img.shields.io/badge/Pandas-Data-green.svg)

A Python-based automation tool designed to streamline the process of filtering, processing, and sharing CSV data. It features a graphical user interface for easy file selection and leverages Pandas for efficient data manipulation. 

## 🚀 Key Features

*   **GUI Interface:** Easy file selection using Tkinter.
*   **Smart Filtering:** Efficient data extraction using Pandas logic.
*   **Automatic Formatting:** Generates clean text summaries with time-aware greetings.
*   **Clipboard Integration:** Automatically copies results for instant sharing via chat or email.

## 🛠️ Tech Stack

*   Python
*   Pandas
*   Tkinter
*   Pyperclip
